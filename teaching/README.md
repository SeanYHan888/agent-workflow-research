## Prepare and teach

1. Read the owning Obsidian project's latest evidence and current state. Check prerequisites and the current weekly allocation.
2. Name one learning question; ask for a prediction or attempt and introduce missing concepts with a small example.
3. Inspect the result together, give the smallest useful hint, then have the student explain or modify the mechanism.
4. Connect it to a selected source passage; verify and record its revision/section.
5. Use the [assessment rubric](../course/ASSESSMENT.md) when evaluating mastery. Record feedback, evidence and actual time in the owning project.
6. Route new interests through [idea intake](../course/IDEAS.md); explain the learning connection and time tradeoff.
