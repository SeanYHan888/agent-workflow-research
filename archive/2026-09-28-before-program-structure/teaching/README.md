# Teaching office

The [roadmap](../ROADMAP.md) owns the course design. This directory holds teaching preparation and original student handouts. Preserve the settled course and expand only the active section into detailed lessons.

## A teaching session

1. Read the current Obsidian project and the learner's latest evidence before preparing the next assignment.
2. Name one concrete question; introduce unfamiliar terms with a small example.
3. Ask for a prediction or attempt, then inspect or run the example together.
4. Give the smallest useful hint. Review the learner's explanation before providing a complete solution.
5. Connect the mechanism to a short passage of actual source; record the revision used.
6. Record feedback and actual study time in the owning Obsidian project. Mark a checkpoint complete only when demonstrated.

All new course-authored material is saved in this classroom. Handouts are initially published into Obsidian; after that, student annotations belong to the Obsidian copy. Revise those notes by merging specific changes, never by blindly replacing them from classroom originals. Personal answers and task states are not mirrored into a competing repo backlog. Exercise locations are named when an exercise is assigned; do not write the learner's solutions during planning.
