# Online resources

Every web resource the course documents link to, grouped by kind, with the pages that assign it. Git repositories already pinned under [sources/](README.md#source-repositories) are omitted because they are in this repository. A link here is not an assignment: the linked course page names the section, its role and the checkpoint it serves.

Regenerate after editing course documents; unversioned sites can change, so record the revision or date when assigning a section.
