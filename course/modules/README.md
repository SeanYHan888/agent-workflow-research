# Module guides

One guide per milestone: outcomes and checkpoints, entry requirements, a project-first lab sequence, failure experiments and the materials in order. The [roadmap](../../ROADMAP.md) owns milestone scope and dependencies; a guide elaborates its row and never adds a required outcome. Some guides cover several milestones.
